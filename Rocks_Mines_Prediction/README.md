# Rocks vs Mines Prediction

A machine learning classification project that predicts whether an object detected by sonar signals is a **Rock** or a **Mine**.

## Algorithm Used

- Logistic Regression

## Libraries Used

- Python
- NumPy
- Pandas
- Scikit-learn

## Dataset

The project uses sonar signal data. Each row contains numerical features representing sonar measurements.

The target variable contains two classes:

- `R` → Rock
- `M` → Mine

## Project Workflow

1. Load the dataset
2. Explore and preprocess the data
3. Separate features and target
4. Split the data into training and testing sets
5. Train the Logistic Regression model
6. Make predictions
7. Evaluate the model using accuracy score

## Files

- `Rocks_Mines_prediction.ipynb` – Complete Python/ML implementation
- `sonar-data.csv` – Dataset
- `README.md` – Project documentation

## Model Evaluation

The model performance is evaluated using **accuracy score** on the test dataset.

## How to Run

Open `Rocks_Mines_prediction.ipynb` in Google Colab or Jupyter Notebook and run the cells sequentially.
